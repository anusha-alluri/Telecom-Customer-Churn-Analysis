#  Telecom Customer Churn Analysis Dashboard

##  Project Overview

This project analyzes telecom customer churn data using Power BI. The dashboard helps identify customer churn patterns, analyze customer behavior, and provide business insights to support customer retention strategies.

---

##  Objectives

- Analyze customer churn trends.
- Identify customer segments with the highest churn.
- Compare churn across contract types, internet services, payment methods, tenure groups, and monthly charge groups.
- Support data-driven business decisions through interactive dashboards.

#     Key Business Insights

- Month-to-month contract customers have the highest churn.
- Fiber optic customers show the highest churn.
- Electronic check users churn the most.
- Customers with tenure below 12 months are more likely to churn.
- Higher monthly charges are associated with higher churn.

##  Project Outcome

This interactive dashboard helps stakeholders monitor customer churn, identify high-risk customer segments, analyze churn patterns, and support data-driven customer retention strategies.
